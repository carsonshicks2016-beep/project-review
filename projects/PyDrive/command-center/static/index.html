FABLEGA Genetic Algorithm vs PPO · Mazda 787B · Nordschleife

same fable-v1 obs (68d) same reward + eval evolution, not gradient

The GA evolves a population of MLP genomes through the same FableEnv PPO trains on — identical car, track, observation, control (steer/long/gear-offset), reward, and the identical FableEvaluator lap eval. Only the optimiser differs. Its [eval-ga] lap is directly comparable to Fable Five’s [eval-fable]. Run one headless job (parallel, strongest); Follow Live Training opens a cheap, read-only window that drives the current champion as training improves it.

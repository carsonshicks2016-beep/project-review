# Python Dojo

An interactive Terminal-based Python tutor powered by local LLMs (via Ollama). 

The application tracks your progress, dynamically generates challenges based on your skill level, and evaluates your code directly in the terminal.

## Prerequisites

1.  **Python 3.10+**
2.  **Ollama:** You must have [Ollama](https://ollama.com/) installed and running locally on your machine.

## Setup & Running

1.  Create a virtual environment and install the requirements:
    ```bash
    python3 -m venv venv
    source venv/bin/activate
    pip install rich prompt_toolkit ollama pydantic
    ```
2.  Run the application:
    ```bash
    python main.py
    ```

*Note: The first time you run it, it may take a minute to download the `llama3.2` model if you don't already have it.*

## How to Play

-   The LLM will generate a prompt and possibly some starter code.
-   Type your solution into the terminal (it supports multi-line input and syntax highlighting!).
-   When you are ready to submit, press **`Esc` followed by `Enter`**.
-   The Dojo will run your code and test it against assertions generated by the LLM. 
-   Solve enough problems correctly, and you will level up to harder concepts!

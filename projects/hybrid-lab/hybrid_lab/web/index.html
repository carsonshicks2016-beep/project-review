Advanced settings

Gamma sets how far ahead the value function looks — 0.99 is about 3 seconds at 30 Hz, 0.995 about 7. The style gate holds the drift bonus back until the car completes that fraction of a lap. Annealing decays the learning rate to the floor by the last update, and the plateau settings revert to the best checkpoint and halve the rate when a run stops improving.

Car, circuit and objective come from the saved run. Everything else above still applies, so this is how you carry a policy forward with different settings.

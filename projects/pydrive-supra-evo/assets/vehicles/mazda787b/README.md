# Mazda 787B #55 Renown clean-room visual reconstruction

This package is a new, deterministic visual reconstruction authored specifically for the Fable Observatory. It uses Mazda's published 4.782 m length, 1.994 m width, 1.003 m height, 2.662 m wheelbase, front/rear tracks, wheel sizes, and tire sizes. Its section-built body includes open wheel arches, a narrow Group-C canopy, four-lamp Cibié-style nose, radiator and side intakes, detailed wheels and brakes, mirrors, rear mechanical treatment, and the #55 Renown color scheme.

Real 787B museum and period photographs were used only for human proportion and detail study. The package contains no OEM CAD, scan, official photograph, third-party model, or geometry/texture from either previous viewer model. All geometry and livery pixels are generated by this project. It is a visual reconstruction—not a surveyed surface, certified likeness, or physics/collision asset.

Build from the repository root:

```bash
python3 tools/build_observatory_assets.py
python3 tools/build_observatory_assets.py --check
python3 assets/vehicles/mazda787b/build_asset.py --check
```

The manifest defines the x-forward, y-left, z-up coordinate contract and stable wheel, suspension, brake, aero, light, exhaust, camera, and audio nodes used by the browser viewer.

# Project Source Review Collection

60 project and variant snapshots from October 7, 2026, gathered into one public link for independent AI review. These substantial works in progress span reinforcement learning, physics, artificial life, simulations and personal tools.

Start with [AI_REVIEW_GUIDE.md](AI_REVIEW_GUIDE.md) and [PROJECTS.json](PROJECTS.json). Each folder has PUBLIC_EXPORT.md describing export limitations.

## What is public

Source code, tests, selected setup files and documentation. Credentials, personal datasets, private migration records, captured lecture material, course-derived teaching content, generated results, media and assets with unclear redistribution permission have been omitted. Personal machine paths, email addresses and LAN addresses were filtered. Some exports require replacement data, assets or dependencies to execute. Tests and applications were not run for this export; historical claims remain claims to independently assess. This collection has fresh history and does not expose the private archives.

## Licenses and attribution

Original notices remain applicable. Bundled components without retained notices were excluded where identified; remaining dependency references require their upstream licenses. This collection assigns no blanket license. Inclusion is not a claim of sole authorship, novelty, validation or production readiness. Projects developed with AI assistance should be assessed from their actual source and evidence.
